## update_prompt_modules

Substitui o objeto INTEIRO dos módulos do prompt de um agente do workspace. Antes: leia o atual com `get_ai_agent` e mande completo, porque não há mesclagem e campo desconhecido recusa tudo, e nunca remova chave que veio de lá; confira com `validate_prompt_modules`; leia o guia `prompt-qualidade` em `get_guide`. Depois: confira `versaoGuardada`, a versão anterior que `rollback_prompt_version` traz de volta, os `avisos` e o `autor`, que aparece quando a chave de API gravou em nome do proprietário. Não faz: comportamento por etapa, ferramentas do agente nem canal.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.edit`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | Id do agente, de list_ai_agents |
| `hashEsperado` | Não | hashDoPrompt da leitura. Obrigatório para gravar; se mudou, leia novamente |
| `tokenConfirmacao` | Não | Token da prévia de remoções ou mudança de nome, após confirmação da pessoa |
| `promptModules` | Sim | Objeto completo dos módulos do prompt. Substitui o que existe, não faz mesclagem |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "agenteId": {
      "type": "string",
      "format": "uuid",
      "description": "Id do agente, de list_ai_agents"
    },
    "hashEsperado": {
      "type": "string",
      "pattern": "^[0-9a-f]{64}$",
      "description": "hashDoPrompt da leitura. Obrigatório para gravar; se mudou, leia novamente"
    },
    "tokenConfirmacao": {
      "type": "string",
      "pattern": "^[0-9a-f]{64}$",
      "description": "Token da prévia de remoções ou mudança de nome, após confirmação da pessoa"
    },
    "promptModules": {
      "type": "object",
      "additionalProperties": {},
      "description": "Objeto completo dos módulos do prompt. Substitui o que existe, não faz mesclagem"
    }
  },
  "required": [
    "agenteId",
    "promptModules"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## create_ai_agent

Cria um agente no workspace; pedido igual em dez minutos reutiliza o cadastro. Antes: `nome` é slug; `modelo` omitido herda o do agente ativo; `promptModules` passa pelo contrato inteiro, então confira com `validate_prompt_modules`; leia o guia `agentes-e-prompt` em `get_guide`. Depois: confira `jaExistia`, `modeloHerdadoDe` e `avisos`; nasce sem canal. Não faz: conectar número novo nem configurar outras tools. Canal existente usa activate_agent_channel; configuração usa o guia operacao-do-workspace; o plano limita agentes.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.create`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `nome` | Sim | Nome do agente no formato slug |
| `modelo` | Não | Modelo de linguagem do agente. Sem ele, o agente herda o modelo do agente ativo mais recente do workspace |
| `descricao` | Não | string |
| `proposito` | Não | support, sales ou personal |
| `estiloDeComunicacao` | Não | formal, normal ou casual |
| `promptModules` | Não | Objeto completo dos módulos do prompt |
| `telefoneHandoff` | Não | string |
| `filaHandoffId` | Não | Fila de handoff do MESMO workspace |
| `statusInicial` | Não | Padrão: inactive |

<Accordion title="Schema completo dos argumentos">

```json

    },
    "estiloDeComunicacao": {
      "type": "string",
      "enum": [
        "formal",
        "normal",
        "casual"
      ],
      "description": "formal, normal ou casual"
    },
    "promptModules": {
      "type": "object",
      "additionalProperties": {},
      "description": "Objeto completo dos módulos do prompt"
    },
    "telefoneHandoff": {
      "type": "string",
      "pattern": "^55\\d{10,11}$"
    },
    "filaHandoffId": {
      "type": "string",
      "format": "uuid",
      "description": "Fila de handoff do MESMO workspace"
    },
    "statusInicial": {
      "type": "string",
      "enum": [
        "active",
```

## activate_agent_channel

Coloca o agente no ar em um canal de WhatsApp já conectado. Primeiro chame sem tokenConfirmacao: recebe a prévia com o agente atual, o novo e o aviso de troca. Mostre a prévia e peça confirmação à pessoa; só depois repita os mesmos ids com o token. Liga o atendimento automático e ativa o agente. Não conecta número novo, não gera QR code e não envia mensagem. Se a configuração mudar, peça outra prévia.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.edit`, `settings.manage_integrations`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `canalId` | Sim | string |
| `tipo` | Sim | string |
| `agenteId` | Sim | string |
| `tokenConfirmacao` | Não | string |

<Accordion title="Schema completo dos argumentos">

```json
  "type": "object",
  "properties": {

      "type": "string",

    },

      "type": "string",

        "uazapi",

      "type": "string",

      "type": "string",
```
