## set_chat_ai_status

Liga ou pausa a IA de uma conversa do workspace e registra a alteração no histórico. Não liga o canal nem muda a situação do agente.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `chats.send`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `conversaId` | Sim | string |
| `ativo` | Sim | boolean |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "conversaId": {
      "type": "string",
      "format": "uuid"
    },
    "ativo": {
      "type": "boolean"
    }
  },
  "required": [
    "conversaId",
    "ativo"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## list_chats

Lista as conversas do workspace com o lead, a última mensagem e as etiquetas

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

Também valem as regras de visibilidade da ferramenta e o escopo da conexão.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `status` | Não | Situação da conversa |
| `busca` | Não | Texto no nome do lead, telefone ou conteúdo |
| `canal` | Não | Canal da conversa |
| `tipo` | Não | Conversas com leads ou conversas internas com a Mysa |
| `page` | Não | Página, começando em 1 (padrão 1) |
| `limit` | Não | Itens por página (padrão 20, teto 50) |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "status": {
      "type": "string",
      "enum": [
        "open",
        "closed",
        "archived"
      ],
      "description": "Situação da conversa"
    },
    "busca": {
      "type": "string",
      "description": "Texto no nome do lead, telefone ou conteúdo"
    },
    "canal": {
      "type": "string",
      "enum": [
        "uazapi",
        "cloud_api",
        "facebook",
        "instagram"
      ],
      "description": "Canal da conversa"
    },
    "tipo": {
      "type": "string",
      "enum": [
        "leads",
        "mysa"
      ],
      "description": "Conversas com leads ou conversas internas com a Mysa"
    },
    "page": {
      "type": "integer",
      "minimum": 1,
      "description": "Página, começando em 1 (padrão 1)"
    },
    "limit": {
      "type": "integer",
      "minimum": 1,
      "maximum": 50,
      "description": "Itens por página (padrão 20, teto 50)"
    }
  },
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>
