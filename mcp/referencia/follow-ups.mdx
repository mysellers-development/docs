## list_followup_rules

Lista as regras de follow-up de um agente do workspace com paginação.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `campaigns.view`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |
| `pagina` | Não | integer |
| `limite` | Não | integer |

<Accordion title="Schema completo dos argumentos">

## create_followup_rule

Cria uma regra de follow-up inativa para o agente. Não envia mensagens. dados segue o contrato do guia de automações. Ative depois com set_followup_rule_status e confirmação.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `campaigns.create`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |
| `dados` | Sim | Campos do contrato: name, delayHours, delayMinutes, suggestedMessage, behaviorInstructions, maxAttempts e filtros. Consulte o guia de automações. |

<Accordion title="Schema completo dos argumentos">

```json

  "type": "object",
  "properties": {
    "agenteId": {
      "type": "string",
      "format": "uuid"

    "dados": {
      "type": "object",

    }
  },
  "required": [
    "agenteId",
    "dados"
  ],
  "additionalProperties": false,
```

## update_followup_rule

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `campaigns.edit`. Também valem as regras de visibilidade da ferramenta.

## set_followup_rule_status

Ativa ou pausa uma regra de follow-up. Ativar exige prévia e confirmação porque permite envios automáticos aos leads elegíveis. Pausar cancela execuções pendentes e remarcadas; reativar não recupera esses cancelamentos. Mensagens já enviadas não são desfeitas.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `campaigns.execute`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `regraId` | Sim | string |
| `ativo` | Sim | boolean |
| `tokenConfirmacao` | Não | string |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "regraId": {
      "type": "string",
      "format": "uuid"
    },
    "ativo": {
      "type": "boolean"
    },
    "tokenConfirmacao": {
      "type": "string",
      "pattern": "^[0-9a-f]{64}$"
    }
  },
  "required": [
    "regraId",
    "ativo"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>
