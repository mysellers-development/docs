## list_knowledge_documents

Lista documentos da base de conhecimento do workspace. Não devolve URLs de storage nem credenciais.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `agents.view`. Também valem as regras de visibilidade da ferramenta.

Não recebe argumentos no perfil cliente.

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {},
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## add_knowledge_text

Enfileira um documento de texto no conhecimento do agente. Consulte o agente antes. Texto de 100 a 50.000 caracteres; não substitui o prompt nem o treinamento. Consulte get_knowledge_job para confirmar o resultado.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.train`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |
| `titulo` | Sim | string |
| `texto` | Sim | string |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "agenteId": {
      "type": "string",
      "format": "uuid"

      "type": "string",
      "minLength": 1,

      "type": "string",
      "minLength": 100,
      "maxLength": 50000

    "agenteId",
```

## update_agent_training_text

Substitui o texto de treinamento e sincroniza com a IA em fila. Leia get_agent_training_text antes e preserve o conteúdo que não foi pedido para remover. Aceita de 100 a 100.000 caracteres. Consulte get_knowledge_job para confirmar gravação e sincronização.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.
