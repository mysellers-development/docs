## get_agent_settings

Consulta os vínculos de calendário e a configuração de voz do agente do workspace. Não devolve tokens das contas.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `agents.view`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "agenteId": {
      "type": "string",
      "format": "uuid"
    }
  },
  "required": [
    "agenteId"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## set_agent_funnels

Substitui os funis associados ao agente. Leia list_agent_funnels antes e envie todos os ids que devem continuar; lista vazia remove todos os vínculos. Só aceita funis do workspace.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.edit`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |
| `funilIds` | Sim | array |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "agenteId": {
      "type": "string",
      "format": "uuid"
    },
    "funilIds": {
      "type": "array",
      "items": {
        "type": "string",
        "format": "uuid"
      },
      "maxItems": 100
    }
  },
  "required": [
    "agenteId",
    "funilIds"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## list_calendar_connections

Lista as contas Google já conectadas e visíveis: contas compartilhadas e a própria; gestores de integrações também veem as demais. Chave de API vê somente contas compartilhadas. Não inicia OAuth.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `agents.view`. Também valem as regras de visibilidade da ferramenta.

Não recebe argumentos no perfil cliente.

<Accordion title="Schema completo dos argumentos">

```json

  "type": "object",
  "properties": {},
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## set_agent_calendar

Configura uma conta Google já conectada e seu calendário no agente do workspace. A API confere acesso à conta pessoal ou compartilhada. Envie null nos dois campos para remover o vínculo. Não conecta contas novas.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.edit`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |
| `conexaoId` | Sim | ver alternativas no schema |
| `calendarioId` | Sim | ver alternativas no schema |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "agenteId": {
      "type": "string",
      "format": "uuid"
    },
    "conexaoId": {
      "anyOf": [
        {
          "type": "string",
          "format": "uuid"
        },
        {
          "type": "null"
        }
      ]
    },
    "calendarioId": {
      "anyOf": [
        {
          "type": "string",
          "minLength": 1
        },
        {
          "type": "null"
        }
      ]
    }
  },
  "required": [
    "agenteId",
    "conexaoId",
    "calendarioId"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## set_agent_voice

Configura a voz e seus parâmetros no agente do workspace. Leia get_agent_settings e preserve parâmetros existentes. vozId=null remove a voz. Não gera nem envia áudio.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `agents.edit`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `agenteId` | Sim | string |
