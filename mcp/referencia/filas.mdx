## get_handoff_queue

Consulta a fila e a régua efetiva do workspace antes de configurar.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `rotation.view`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `filaId` | Sim | string |

      "type": "string",
      "format": "uuid"

    "filaId"
  ],

## create_handoff_queue

Cria uma fila de transferência no workspace. Não distribui leads nem envia mensagens. dados segue o contrato de fila do guia de operação.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `rotation.manage`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `dados` | Sim | Campos do contrato de fila: name, mode, code, isActive, assignLeadOwner e régua. Consulte o guia de operação. workspaceId não é aceito. |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "dados": {
      "type": "object",
      "additionalProperties": {},
      "description": "Campos do contrato de fila: name, mode, code, isActive, assignLeadOwner e régua. Consulte o guia de operação. workspaceId não é aceito."
    }
  },
  "required": [
    "dados"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## list_handoff_queues

Lista as filas de transferência do workspace com nome, situação e modo. Use o id ao ajustar a fila do agente por update_ai_agent. Não altera a fila nem envia aviso aos operadores.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `rotation.view`. Também valem as regras de visibilidade da ferramenta.

Não recebe argumentos no perfil cliente.

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {},
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>
