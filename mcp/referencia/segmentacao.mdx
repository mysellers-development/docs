## list_tags

Lista as etiquetas disponíveis no workspace. Use os ids para etiquetar leads.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

Também valem as regras de visibilidade da ferramenta e o escopo da conexão.

Não recebe argumentos no perfil cliente.

```json
  "properties": {},
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

## create_tag

Cria uma etiqueta no workspace. Cor em #RRGGBB ou #RRGGBBAA.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `settings.manage_tags`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `nome` | Sim | string |
| `descricao` | Não | string |
| `cor` | Sim | string |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "nome": {
      "type": "string",
      "minLength": 1,
      "maxLength": 255
    },
    "descricao": {
      "type": "string"
    },
    "cor": {
      "type": "string",
      "pattern": "^#([A-Fa-f0-9]{6}|[A-Fa-f0-9]{8})$"
    }
  },
  "required": [
    "nome",
    "cor"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## update_segmented_list

Edita nome, descrição, regras (v2) ou ativação de um segmento. ativa = atualizar sozinha (desligado congela a lista a partir da entrega 2). Regras substituem o objeto anterior; leia get_segmented_list e preserve os filtros que não foram pedidos para remover. Um filtro de lista restrita (outra_lista com listaId null): reenviar a regra igual não muda nada; para mudar a regra, remova o filtro de lista restrita.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `leads.edit`. Também valem as regras de visibilidade da ferramenta.
