## list_myflows

Lista os MyFlows do workspace, incluindo inativos. Não devolve segredos de webhook nem credenciais.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `flows.view`. Também valem as regras de visibilidade da ferramenta.

Não recebe argumentos no perfil cliente.

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {},
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## get_myflow

Lê o grafo, o gatilho e a versão de um MyFlow do workspace. Leia antes de editar; a versão protege alterações concorrentes do painel.

**Escopo:** `mysellers:read`. **Operação:** consulta ou validação sem gravação de dados de negócio.

**Permissões adicionais no OAuth:** `flows.view`. Também valem as regras de visibilidade da ferramenta.

## create_myflow

Cria um MyFlow inativo. graph é o grafo completo nodes/edges do contrato MyFlows, sem credenciais literais. Consulte o guia de automações antes. Para ativar, use set_myflow_status.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `flows.manage`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `nome` | Sim | string |
| `descricao` | Não | string |
| `graph` | Sim | object |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "nome": {
      "type": "string",
      "minLength": 1,
      "maxLength": 200
    },
    "descricao": {
      "type": "string"
    },
    "graph": {
      "type": "object",
      "additionalProperties": {}
    }
  },
  "required": [
    "nome",
    "graph"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

</Accordion>

## update_myflow

Edita um MyFlow usando a versão de get_myflow. dados: name, description, graph, triggerType ou triggerConfig. Graph substitui o grafo completo. Se estiver ativo, exige prévia e confirmação porque muda a automação em execução.

**Escopo:** `mysellers:write`. **Operação:** altera dados; exige assinatura ativa do cliente.

**Permissões adicionais no OAuth:** `flows.manage`. Também valem as regras de visibilidade da ferramenta.

| Argumento | Obrigatório no schema | Descrição |
| --- | --- | --- |
| `fluxoId` | Sim | string |
| `versao` | Sim | integer |
| `dados` | Sim | object |
| `tokenConfirmacao` | Não | string |

<Accordion title="Schema completo dos argumentos">

```json
{
  "type": "object",
  "properties": {
    "fluxoId": {
      "type": "string",
      "format": "uuid"
    },
    "versao": {
      "type": "integer",
      "minimum": 1
    },
    "dados": {
      "type": "object",
      "additionalProperties": {}
    },
    "tokenConfirmacao": {
      "type": "string",
      "pattern": "^[0-9a-f]{64}$"
    }
  },
  "required": [
    "fluxoId",
    "versao",
    "dados"
  ],
  "additionalProperties": false,

}
```
